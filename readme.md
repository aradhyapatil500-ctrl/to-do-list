# 📝 To-Do List (Python)

A simple command-line To-Do List application built with Python.

## Features

- View tasks
- Add new tasks
- Delete tasks
- Saves tasks in a text file

## Project Structure

```text
todo-app/
│
├── main.py
├── tasks.txt
├── README.md
└── requirements.txt
```

## Requirements

- Python 3.x

## How to Run

```bash
python main.py
```

## Example Menu

```
===== TO-DO LIST =====
1. View Tasks
2. Add Task
3. Delete Task
4. Exit
```

- Python
- File Handling
